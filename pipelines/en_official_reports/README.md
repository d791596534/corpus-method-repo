# 英文公文 · 美国内政部 / 劳工部年度部长报告 + 总统国情咨文

年代跨度 1900–2026，13 个年代桶全部建成，实得 **324.5 万词**（配额 13 格 × 25 万词，
达成 99.8%，逐格 24.1 万–25.1 万；换用只数纯字母序列的保守口径则为 314.5 万）。
成品与少量源件样本在 [`data/en_official_reports`](../../data/en_official_reports)。

源文件是美国联邦政府的年度出版物：1900–1963 为内政部长报告，1964 年起改由劳工部长发布，
2020 年代另补 APP&R 报告。总统国情咨文取一份公开的 SOTU 全文汇编，
其中 2020 年代的条目夹着发言人标签与舞台指示（`THE VICE PRESIDENT:`、`AUDIENCE:` 一类），单独过一条清噪链。
联邦政府出版物依 **17 U.S.C. §105** 不受著作权保护，对公版文本做 OCR 产出的文字也不产生新权利，
因此本子库的**正文与政府原生电子档源件可以随仓库发布**；
来自图书馆数字化本的扫描影像不再分发，理由见数据目录。

## 管线

```
01_extract           源 PDF → 版面解析结果 → 只留正文段落
02_clean_denoise     行级清噪 → 分句 → 删残句 → 按年代归并 → 二次清噪
03_integrate_2020s   2020s 两源按年合并
04_sotu_clean        2020s 讲话稿去噪
05_select_supplement 按「年代 × 体裁」配额选句、补足词量
```

| 阶段 | 脚本 | 作用 |
|---|---|---|

## 清洗判据

- **删除**：非空且整行不含小写字母、字母数字个数 ≥3 的行（纯大写标题行、分隔符行、页码）；
  大小写混杂且词内中段大写占比 ≥50% 的行；剥掉行首全部非字母数字后成为残句的行。
  第一条不是 `str.isupper()`——那样会漏掉 `INT 1900—12`、`72422—21—2` 这类带数字与破折号的行。
- **保留**：列表行。实测仅占 0.6% 词量，且多为完整语义句，删除的代价高于收益。
- **上下标**：MinerU 的文字层会把小号数字误判成 `<sub>/<sup>`，数字本身没错，所以只剥壳不删内容。
  这一步放在抽取阶段而非清洗阶段：标签一旦进了分句层，会被切成两句。
- **表格**：1998–2003 批次在 OCR prompt 里直接要求屏蔽，而不是识别后再删——
  事后删除会把跨页表格的碎片留在正文中。
- **页界续段**：1998–2003 是逐页 OCR，页与页相接处要决定「另起一段」还是「句子被版面折断了」。
  判据取形式特征：下一页首行不以小写字母开头，或上一页末行以句末终止符收尾（终止符后可跟右引号、
  右括号）→ 断开，否则接在同一段。1998–2003 全部 956 处页界都由这条判据定，不需要逐页人工判断。
- **1998–2003 单独一条清洗链**：视觉模型批次的错误分布与 MinerU pipeline 不同
  （表格更干净、加粗残留更多），因此不与其它年代共用。

## 运行

```bash
export CORPUS_ROOT=/path/to/corpus     # 源 PDF 与中间产物的根目录，不设则取当前目录
export LLM_API_KEY=...                 # 仅 1998–2003 视觉 OCR 批次需要
pip install mineru==3.4.0 pysbd
```

`$CORPUS_ROOT` 下的目录由脚本自己拼，不用手建：

| 目录 | 谁写 | 内容 |
|---|---|---|
| `pdf/` | 自备 | 源 PDF，`<年>_report of the secretary of *.pdf` |
| `pdf_2020s_interior/` | 自备 | 2020s 内政部补源，`<年>.pdf` |
| `pdf_png_1998_2003/` | `01/_pdf_to_png_1998_2003.py` | 逐页 PNG 300dpi |
| `_mineru_out_<批次>/` | `01/_mineru_*.py` | MinerU 版面输出，`<年>/ocr|txt/*_content_list_v2.json` |
| `英文公文1998-2003_OCR_v2/` | `01/_dsocr_1998_2003.py` | 视觉模型逐页 OCR，`<年>/<页>.txt` |
| `英文公文<批次>_正文/` | `01/_extract_paragraphs.py`（由 `01/_mineru_*.py` 调用）；1998–2003 由 `02/_merge_pages.py` 拼出 | 只留 paragraph 的抽取结果，逐年一个 `<年>.txt` |
| `英文公文1998-2003_去加粗_v2/` | `02/_del_bold_headings.py --write` | 去加粗四条判据作用后的逐页结果 |
| `英文公文<批次>_正文_去大写/`（`_去sub`） | `02/_caplines_and_desub.py --write` | 行级清噪 |
| `英文公文<批次>_…_分句/`、`_分句_清残句/` | `02/_pysbd_eng.py`、`02/_clean_fragments.py` | 句级，仍是逐年平铺 |
| `英文公文_分句_清残句_按十年/`（`_清噪`） | `02/_merge_decade.py`、`02/_denoise_decade.py`；`03` 改写其中 `2020s/` | 报告侧成品池 |
| `sotu/<年代>/` | 自备 | 总统讲话原文，一篇一个 `<年>_<总统>.txt` |
| `sotu/2020s/`（`_清噪`） | 自备（`04` 写 `_清噪`） | 2020s 取白宫稿 `<年>.txt`，去噪后一句一行 |
| `sotu/_每时期25000词_句净/`、`sotu/_每时期250000词/` | `05` | 选句切片与补足后的成品 |

跨阶段调用按 `__file__` 相对定位，用 `importlib` 直接加载仓库内的脚本（`01` 调同目录的
`_extract_paragraphs.py`，`03` 调 `02` 的清残句与清噪函数），不需要配 `sys.path`。
每一步写入新目录、源目录不动，可整步重跑；`--verify` 模式只读比对，不产出文件。
从 `01` 的抽取层起把 `02`–`05` 整条链重放一遍，成品 247 个文件与
[`data/en_official_reports/cleaned`](../../data/en_official_reports) 逐字节相同（3,244,916 词）。

`data/en_official_reports/sources` 只有 2004–2026 的 5 个样本，够跑通 `-m txt` 那一支；
1900–1993 与 1998–2003 的源件要自行补齐，文件名按年份对齐即可，脚本只按年份匹配。

## 抽样口径

配额单位是「年代 × 体裁」，本体裁为 25 万词/年代。句子是最小截取单位：
按句数分配步长，加入下一句会超出目标即停止，不从句中切断。
词数口径见 `05_select_supplement/_supplement_en250k.py` 的 `TOKEN`：连续字母、数字与词内撇号算一词，
标点与杂符不计入。逐年代词数见 [`data/en_official_reports`](../../data/en_official_reports)。

## 数据缺口

- 1994–1997、2005 无源 PDF，对应年代由相邻年份补足，故该两格词量略低但仍达标。
- 2026 无内政部新报告，2020s 报告源实际约 13.5 万词，该格 23.7 万词是全库最低格之一。
